# Paw Club - a Pet Shop Blueprint

Designs, assets, and requirements for a pet shop example web app inspired by Düsseldorf and the [Swagger Petstore](https://petstore3.swagger.io/) API.

## About

Paw Club is my personal project covering pet browsing, customer accounts, orders, and shop administration.

## What's in this repository

- Brand guidelines and UI designs
- Page layouts and interaction flows
- Illustrations and test assets
- Requirements, business rules, and proposed data models and APIs

Frontend and backend code not included, will be done separately.
